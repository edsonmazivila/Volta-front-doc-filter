## 👥 Access Control and Permissions

### 👑 Admin
- Access to all menus: Dashboard, Employees, Timesheets, Payroll, Reports, Users.
- **Applied fix:** Users menu now visible on all routes.
- Complete permissions over all entities and functionalities.

### 👔 Manager
- Can process payroll and view team timesheet.
- Can edit only timesheet status (Approved/Rejected).
- Full access to Employees, Timesheets and Reports.

### 👷🏽‍♂️ Employee
- Can create and edit their own timesheets (Status: Draft/Submited).
- No access to payroll.
- Can edit their data in Employees, but cannot remove.
- No access to Reports module.
- **Applied fix:** Payroll option removed from menu.
